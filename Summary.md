# CiviVigi is a MERN safety-reporting platform (web and USSD).
## Summary
Reports are verified by province-assigned Security Officials, then alerted via WhatsApp and social media. Built with Claude, 
checked by build and code review, tested against a live database, but not with real telecom accounts.

## Process:
Built backend-first in dependency order: models, services, controllers, then frontend, seed data, and Readme following a written spec, verifying each layer as it landed.

## Information sources:
Researched web sources, especially https://westafrica.civichive.org. But the core Idea is was gotten from my community's need.
Having interviewed a few people.


## Approach to trust and accuracy
The project has been tested locally. It is production-ready. Third-party integrations are mocked behind environment variables, never faked, and untested gaps are stated plainly.

## Use of AI tools in this project
Built in close collaboration with Claude, who wrote nearly all the code and ran verification. I supplied requirements, made every open decision, reviewed each diff, and am accountable for the result.
